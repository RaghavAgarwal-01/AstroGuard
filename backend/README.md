# AstroGuard — Backend (Person 1)

FastAPI backend: TLE data → SGP4 propagation → conjunction detection → AI risk summaries.

## Quick Start

```bash
# 1. Install
pip install -r requirements.txt

# 2. Set API key
cp .env.example .env
# Edit .env and add your ANTHROPIC_API_KEY

# 3. Download TLE data
python tle_fetcher.py

# 4. Pre-compute cache (do this before the demo!)
python cache_results.py

# 5. Start server
uvicorn server:app --reload --port 8000
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/objects` | All satellite current positions |
| GET | `/api/objects?cached=true` | Same, from cache (fast) |
| POST | `/api/run-analysis` | Run full pipeline |
| POST | `/api/run-analysis?cached=true` | Return pre-computed results |
| GET | `/api/ai-summary/{event_id}` | AI risk briefing for one event |
| GET | `/api/health` | Server status + config check |

## Response Contracts (for P2 Frontend)

### GET /api/objects
```json
[
  {"name": "ISS (ZARYA)", "lat": 28.4, "lon": -80.6, "alt_km": 408},
  ...
]
```

### POST /api/run-analysis
```json
{
  "events": [
    {
      "id": 0,
      "obj_a": "ISS (ZARYA)",
      "obj_b": "FENGYUN 1C DEB",
      "min_dist_km": 4.2,
      "closest_time": "2026-06-14T18:32:00Z",
      "rel_velocity_kms": 7.1,
      "risk_level": "critical"
    }
  ],
  "objects": [...],
  "analysis_time_s": 12.4,
  "total_objects": 185
}
```

### GET /api/ai-summary/0
```json
{
  "event_id": 0,
  "summary": "At 18:32 UTC, ISS will pass within 4.2 km of Cosmos debris fragment ...",
  "recommendation": "REVIEW_MANEUVER",
  "explanation": "Distance below 5 km critical threshold."
}
```

## File Structure

```
backend/
├── server.py          # FastAPI app — entry point
├── propagator.py      # SGP4 orbit engine
├── conjunction.py     # Close-approach detector
├── ai_summary.py      # Anthropic API integration
├── coord_utils.py     # ECI → lat/lon/alt (shared with P3)
├── tle_fetcher.py     # CelesTrak downloader (run once)
├── cache_results.py   # Pre-compute demo cache (run once)
├── requirements.txt
├── .env.example
└── data/
    ├── tle_active.txt      (generated by tle_fetcher.py)
    ├── tle_debris.txt      (generated by tle_fetcher.py)
    └── sample_results.json (generated by cache_results.py)
```
